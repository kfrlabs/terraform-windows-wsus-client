# Security Policy

## Supported Versions

Only the `main` branch is supported with security updates. This module is
pre-`1.0`; pin a tagged version in production and follow release notes for
security-relevant changes.

| Version | Supported |
| ------- | --------- |
| `main` (latest) | Yes |
| Older tags / forks | No |

## Reporting a Vulnerability

Report vulnerabilities privately via
[GitHub Private Vulnerability Reporting](../../security/advisories/new)
(`Security` tab → `Advisories` → `Report a vulnerability`). Do not open a
public issue for a suspected vulnerability.

## Response Targets

- Acknowledgement: within 5 business days.
- Assessment and remediation plan: within 15 business days.
- Coordinated disclosure once a fix is available; credit on request.
